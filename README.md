## Important Clarification

UZDT is an independent decentralized community DeFi digital asset.

UZDT is not USDT, not Tether, not a stablecoin, not government-issued, not fiat-backed, and not affiliated with Tether Limited or any official stablecoin issuer.

The token has market-driven value and operates as an independent digital asset.
